### Ce qu’il faut créer (standards Home Assistant / HACS – OBLIGATOIRE)

1. **Icône d’intégration** (la plus importante – s’affiche dans HACS et Lovelace)

→ **Nom du fichier** : `electric_heater.png`

→ **Format** : PNG uniquement

→ **Tailles exactes** :

• 192 × 192 px → **OBLIGATOIRE**

• 512 × 512 px → fortement recommandé (store HACS officiel)

→ Fond transparent

→ Icône centrée, pas de bordure

2. **Logo principal** (GitHub, README, bannière)

→ **Nom du fichier** : `logo.png` (ou `logo.svg` si vectoriel)

→ **Format** : PNG ou SVG

→ **Taille recommandée** : 1200 × 600 px (ratio 2:1)

→ Fond transparent
